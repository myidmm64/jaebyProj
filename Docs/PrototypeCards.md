# 카드·코스튬 기획 v2 — 공통·폭렬

> 이전 기획 보관 문서. 최신 콘셉트는 [거합·공허 탐험 v3](IaiConcept-v3.md)를 따른다.

## 기획 상태

이 문서는 기존 19종 카드안을 대체한다. 사냥꾼·복합 계열·표식·피해 전달·기존 합성 촉매·잔상탄은 이번 카드 풀에서 제외한다. 게임 코드 구현 완료를 뜻하지 않는다.

**사용자 확정:** 공통·폭렬 두 계열, 동일 카드 2장으로 성급 강화 및 턴 제한 초기화, 마나 충전 스택을 특정 폭렬 마법으로 전량 소비, 카드 안에 공격 범위 그림 표시, 카드 세팅 → 이동 → 공격 순서. 캐릭터 선택 대신 획득 코스튬을 인게임에서 장착해 외형·궁극기·무기를 변경하며 코스튬도 성급 강화한다. 첫 폭렬 코스튬 궁극기는 '대폭렬' 카드 한 장을 지급하고, 이 카드는 한 번 쓰면 사라지며 쓰지 않아도 사라진다.

**아래 세부안은 테스트 제안:** 동일 성급끼리 합체, 최대 ★3, 시퀀스 6슬롯, 턴당 이동 2칸, 마나 상한 12, 카드별 수치·수명·범위, 코스튬 교체 시점, 궁극기 충전 방식. 사용자 확정과 구분한다.

## 1. 한 턴의 흐름

1. 적 행동 예고를 표시한다. 예정 공격 칸은 이번 턴 동안 고정한다.
2. **카드 세팅:** 보유 카드에서 6개 슬롯에 배치하고 순서를 조정한다. 카드·코스튬 합체, 코스튬 교체, 궁극기 사용도 이 단계에서 한다. 모든 카드는 한 칸을 차지한다. 빈칸은 건너뛴다.
3. **이동:** 맨해튼 거리 기준 최대 2칸 이동하고 상하좌우 중 공격 방향 하나를 정한다. 카드별 범위가 그 방향으로 회전한다. 이동 가능 여부는 Stage의 유효 칸과 점유 상태로 판단한다.
4. 이동 중에는 카드를 고치지 못한다. 공격 확정 전 '세팅으로 돌아가기'를 누르면 이동·방향을 턴 시작 상태로 되돌린다. 되돌리기는 적 행동, 자원 획득, 궁극기 재지급을 발생시키지 않는다.
5. **공격:** 확정 위치·방향에서 슬롯 순서대로 카드를 실행한다. 카드는 이동이나 별도 자유 조준을 만들지 않는다. 각 카드 실행 직전에 현재 적 생존 상태와 범위를 다시 검사한다.
6. 플레이어 공격 종료 후 카드 수명·임시 카드·버프를 정리한다. 모든 적이 죽었으면 전투를 끝내고, 아니면 살아남은 적이 예고 행동을 한다.
7. 다음 턴. 일반 마나는 남으며 코스튬 무기의 턴당 발동 횟수는 초기화한다.

전투 승리로 시퀀스가 중단돼도 종료 정리는 실행한다. 죽은 적의 행동은 취소한다. 미리보기는 실제 카드 계산 순서를 재현한다.

## 2. 마나 충전과 소비

- 플레이어 공용 상태 `마나 충전 M`: 0~12. 남은 마나는 다음 턴으로 이어지고 전투 종료 시 0이 된다. 전투 중 코스튬 교체는 마나를 바꾸지 않는다.
- '충전' 카드가 마나를 쌓는다. 공격 카드의 명중 충전은 적 수·타수와 무관하게 카드당 한 번이다. 서포트 충전은 적이 없어도 실행한다.
- 일반 마법은 마나를 소비하지 않는다. 명시된 '전량 소비' 마법만 실행 직전 M을 읽고 전부 소비한다.
- 일반 전량 소비 마법은 M ≥ 1이고 범위 안에 적이 있을 때만 실행한다. 조건이 안 맞으면 건너뛰며 마나와 다음 공격 버프를 소비하지 않는다. 배치 카드의 수명은 별도 규칙대로 감소한다.
- 전량 소비 마법의 마나는 적별·타격별로 나누지 않는다. 한 번 소비한 M으로 범위 내 각 적의 피해를 계산한다. 뒤의 소비 마법은 앞 카드 이후 남은 마나만 사용한다.
- **대폭렬은 예외:** M=0이어도 사용할 수 있고, M>0이면 모두 소비해 강화한다. 적이 없으면 실행하지 않지만 턴 만료로 사라진다.
- 임시 피해 강화는 턴 사이에 유지되지 않는다. '집중'은 다음 유효 공격의 첫 타격에 적용된다. '점화'는 다음 유효 전량 소비 마법에 적용되며 대폭렬도 대상이다. 같은 종류의 강화 여러 장은 수치를 더한다.
- 공격마다 대상별 피해를 계산한 뒤 소수점 이하는 버린다. 최종 피해 = (기본 피해 + 마나 계수 × 소비 M + 첫 타격 고정 보너스) × (1 + 점화 배율 합). 마나 계수는 해당 카드에만 존재한다. 첫 프로토타입은 방어력·치명타를 제외한다.

## 3. 합체와 턴 제한

- 세팅 단계에 동일 ID·동일 성급 카드 2장을 합쳐 다음 성급 카드 1장을 만든다. ★1+★1→★2, ★2+★2→★3. 최대 성급은 초안상 ★3이고 ★3끼리는 합체하지 않는다.
- **합체 결과의 남은 턴은 새 성급의 기본 제한 턴으로 완전히 초기화된다.** 재료의 남은 턴을 더하거나 낮은 값을 계승하지 않는다.
- 예: 남은 1턴 응축 ★1 + 남은 2턴 응축 ★1 → 응축 ★2, 남은 6턴.
- 재료 카드는 모두 제거된다. 배치 카드에 다른 카드를 끌어 합체하면 그 슬롯을 유지한다. 보관함끼리 합치면 보관함에 둔다. 재료의 서로 다른 성급은 합체 불가다.
- 일반 제한 카드는 **공격 단계 시작 시 배치되어 있던 카드마다 그 단계 종료 시 1턴 감소**한다. 빗나감·마나 부족·전투 조기 종료로 실제 공격하지 못해도 감소한다. 이를 확정 버튼 전에 표시한다.
- 보관함의 일반 카드는 턴이 감소하지 않는다. 전투 사이에 남은 턴은 유지한다. 0이 된 카드는 소유 목록에서 제거되어 이번 런에서 자동 복구되지 않는다.
- 무제한 기본 카드도 합체할 수 있지만 수명 표시는 없다. 배치·해제·코스튬 교체는 남은 턴을 초기화하지 않는다.
- **대폭렬은 생성된 턴 한정 + 사용 1회 한정.** 발동 직후 제거되며, 미배치·미사용·전투 조기 종료여도 그 턴 플레이어 공격 단계 종료 또는 전투 종료 중 먼저 오는 시점에 제거된다. 보관으로 만료를 피할 수 없고 합체·판매·복제도 불가다.
- 수치 성장과 수명은 분리한다. 아래 일반 카드는 ★1~★3의 기본 수명이 같고 피해·충전량만 달라진다. 궁극기 카드의 성급은 생성 시 코스튬 성급을 따른다.

## 4. 범위 표시와 판정

이누야샤 플래시게임처럼 카드 안의 작은 격자 그림으로 패턴을 보여준다. P=플레이어, X=공격 칸, C=폭발 중심(동시에 공격 칸), 점=빈칸. 기본 그림은 위쪽을 바라본 기준이다. 방향 선택 시 실제 전장 오버레이는 회전한다.

| 코드 | 범위 | 판정 |
| --- | --- | --- |
| S | 자신 | 충전·강화 서포트. 공격 칸 없음 |
| L3 | 전방 직선 3칸 | 가까운 적 하나. 중간 적과 벽이 막음 |
| P3 | 전방 직선 3칸 | 선 위 모든 적. 적은 관통하고 벽은 막음 |
| N4 | 자신의 상하좌우 1칸 | 해당 칸 모든 적 |
| B5 | 전방 2칸을 중심으로 십자 5칸 | 모든 해당 적에게 동일 피해 |
| P4 | 전방 직선 4칸 | 선 위 모든 적. 적은 관통하고 벽은 막음 |
| U25 | 전방 3칸을 중심으로 5×5 | 대폭렬 전용, 범위 내 모든 적. 벽 차폐 무시 |

B5 중심은 (0,2), 오프셋은 (0,1),(-1,2),(0,2),(1,2),(0,3). 중심으로 가는 직선에 벽이 있으면 공격 불가, 유효 중심에 도착한 폭발의 칸별 차폐는 프로토타입에서 생략한다. 모든 범위는 맵 밖 칸을 잘라내고 플레이어·아군에는 피해를 주지 않는다. 캐릭터 이동 불가 지형과 투사체 차폐 벽은 별도 플래그로 정의한다.

## 6. 코스튬 시스템

- 런 시작 시 캐릭터 선택 화면 대신 기본 외형으로 시작한다. 코스튬 획득·장착이 외형, 장착 무기, 궁극기를 함께 교체한다. 첫 프로토타입은 첫 보상으로 폭렬 코스튬을 확정 지급한다.
- 코스튬은 여러 개 보유할 수 있고 하나만 장착한다. 전투 중에는 카드 세팅 단계에서만 교체 가능하다. 이동·공격 중 획득한 코스튬은 다음 세팅 단계에 장착할 수 있다.
- 무기는 해당 코스튬에 포함된 고정 무기다. 첫 버전에서는 무기 별도 교체·강화를 만들지 않는다. 코스튬 성급이 무기 효과와 궁극기 카드 성급을 강화한다.
- 코스튬 교체 시 현재 체력·최대 체력·보유 카드·카드 수명·마나·패시브·궁극기 게이지는 유지한다. 장착 무기 효과와 궁극기 종류만 바뀐다. 중복 코스튬 수집은 다른 캐릭터의 별도 체력을 제공하지 않는다.
- 동일 코스튬·동일 성급 2개를 합쳐 성급 +1, 초안 최대 ★3. 코스튬에는 턴 제한이 없다. 장착 중인 코스튬을 합체하면 장착 상태를 유지하며 새 성급을 적용한다.
- 턴당 무기 추가 효과 발동 여부는 플레이어 공용으로 기록해 세팅 중 교체·재장착으로 초기화하지 않는다. 실제 공격 단계에는 최종 장착 무기 하나만 적용된다.

## 7. 첫 코스튬 — 잿불의 폭렬술사

**외형 초안:** 검붉은 짧은 로브, 그을린 마법사 모자, 주황색 마력 균열. **무기:** 잿불 지팡이. **전용 궁극기:** 대폭렬 카드 생성.

| 성급 | 무기 효과 | 궁극기로 얻는 카드 |
| --- | --- | --- |
| ★1 | 매 턴 첫 폭렬 카드의 마나 획득 이벤트에 마나 +1 | 대폭렬 ★1 |
| ★2 | 같은 조건에 마나 +2 | 대폭렬 ★2 |
| ★3 | 같은 조건에 마나 +3 | 대폭렬 ★3 |

카드 본래의 마나 획득이 먼저 발생하고 무기 추가량을 적용한 뒤 상한 12로 제한한다. 이미 상한이어도 해당 턴 추가 효과는 사용한 것으로 처리한다. 추가 마나는 추가 획득 이벤트를 발생시키지 않는다. 일반 소비 마법이나 대폭렬 자체에는 충전 효과가 없어 무기 효과를 발동시키지 않는다.

### 궁극기 버튼과 게이지 — 테스트 제안

- 궁극기 게이지는 플레이어 공용 0~100. 첫 전투 진입 시 0이고 다음 전투로 유지한다. 마나와 별개다.
- 궁극기 카드 이외의 공격 카드가 적을 한 번이라도 맞힌 턴의 공격 단계 종료 시 +25. 적 수·카드 수·타수와 무관하게 턴당 최대 +25.
- 세팅 단계에 게이지 100이면 궁극기를 사용할 수 있다. 사용 즉시 100을 소비하고 현재 코스튬의 대폭렬 카드 1장을 임시 보관 영역에 지급한다. 일반 보관함이 가득 차도 지급은 가능하다.
- 대폭렬도 시퀀스 한 슬롯을 차지한다. 임시 영역에서 배치하지 않으면 자동 공격하지 않는다. 취소·보관·미사용으로 게이지를 환불하지 않는다. 획득 시 '이번 턴에 사용하지 않으면 사라집니다'를 표시한다.
- 생성된 대폭렬의 성급은 생성 순간 확정한다. 이후 같은 세팅 단계에 코스튬을 강화하거나 교체해도 카드가 바뀌거나 추가 지급되지 않는다. 세팅 복귀·저장 불러오기로 생성 턴과 사용 여부를 초기화하지 않는다.
- 대폭렬 자체는 궁극기 게이지 획득 조건에서 제외한다. 같은 턴 다른 일반 공격이 명중했다면 정상적으로 +25를 얻는다.

## 8. 배치 검증 예시

모두 ★1, 마나 0 시작, 폭렬 코스튬 ★1, 관련 범위에 적이 있고 피해 보정 없음 기준.

1. **충전 후 폭렬:** 응축 → 불씨탄 → 폭렬. 응축 2 + 무기 1 = M3, 불씨탄 명중 후 M4, 폭렬 8+4×4=24 피해를 해당 적마다 주고 M0. 불씨탄에 맞은 적은 앞서 6 피해도 받는다.
2. **저장:** 응축 → 불씨탄, 소비 마법 없음. M4를 다음 턴으로 넘긴다. 다음 턴 응축(무기 포함 +3) → 불씨탄(+1) → 점화 → 폭렬이면 M8, 폭렬 내림((8+4×8)×1.25)=50 피해.
3. **궁극기 턴:** 게이지 100에서 대폭렬 획득, 응축 → 불씨탄 → 점화 → 대폭렬 배치. M4를 소모해 내림((40+8×4)×1.25)=90 피해, 카드 즉시 소멸. 불씨탄이 명중했으므로 공격 종료 후 게이지 25.
4. **소비 순서 주의:** 응축 → 폭렬 → 대폭렬이면 폭렬이 M3을 먼저 소모해 20 피해, 대폭렬은 M0의 기본 40 피해만 낸다. 순서·공격 범위와 예상 마나를 UI에 표시한다.
5. **수명 초기화:** 응축 ★1 두 장이 각각 1턴·2턴 남았어도 합체 결과는 응축 ★2 6턴. 그 턴 배치해 공격 단계를 끝내면 5턴이 된다.
6. **대폭렬 미사용:** 임시 보관 영역에 남겨 두고 공격하면 턴 끝에 소멸. 일반 카드를 장착하지 않고 이동만 끝내도 만료한다. 전투가 앞 카드로 먼저 끝나도 소멸한다.

## 9. 초기 지급·보상과 수명 공급

- 시작 카드 초안: 마력탄 1, 불씨탄 1, 응축 2, 폭렬 1. 첫 보상에서 폭렬 코스튬을 획득한다. 응축 두 장을 나눠 충전할지 합쳐 슬롯과 수명을 확보할지 선택하게 한다.
- 기본 무제한 카드를 남겨 제한 카드가 소진돼도 전투 불능이 되지 않게 한다.
- 전투는 우선 3턴 내외 웨이브로 검증하고 웨이브 사이 카드 3장 중 1장 선택 보상을 둔다. 첫 보상 선택지에는 보유 중인 제한 카드의 동일 ID·성급 후보 하나를 보장한다. 일반 소비 카드가 계속 공급되는지 테스트한다.
- 수명이 6턴이면 대략 두 웨이브에 한 번 보충할 필요가 있다. 실제 전투 길이에 따라 수명과 보상 주기를 함께 조정한다. ★3 수명 고갈 이후 재획득 부담과 최대 성급 유지 방식은 플레이 테스트 후 결정한다.
- 코스튬 첫 획득은 확정, 중복 획득·타 계열 코스튬의 드롭 주기는 후속 설계한다.

## 10. 카드 UI·구현용 최소 정의

- 좌측 위 예상 1타 피해 × 타수, 우측 위 ★ 성급. 예상 피해는 해당 슬롯 도달 시점의 마나를 반영한다. 광역의 수치는 적 1명 기준이다.
- 카드 중앙은 그림과 이름, 계열/종류 띠는 '폭렬 / 공격' 또는 '공통 / 서포트'의 2칸. 충전·전량 소비·일회용은 설명 영역의 키워드로 표시한다.
- 설명 영역 안에 공격 범위 격자를 넣고 플레이어 기준점·방향·영향 칸·관통 여부를 구분한다. 서포트는 자신 적용 아이콘을 표시한다.
- 하단 모래시계는 일반 카드 '남은 N턴'. 대폭렬은 '이번 턴 한정 · 1회용'을 함께 표시해 일반 보관 수명 규칙과 구분한다.
- 시퀀스 아래 보유 가방, 패시브는 오른쪽 획득 목록. 코스튬 슬롯에는 외형·성급·무기 효과·궁극기를 묶어 보여준다.
- 정의 데이터: 카드 ID, 계열, 종류, 성급별 피해/마나/강화량, 범위 오프셋, 판정 방식, 기본 수명, 합체 가능 여부, 마나 소비 정책, 만료 정책. 소유 인스턴스: 성급, 남은 턴, 생성 턴, 임시 카드 여부. 기존 카드 ID를 재사용해 옛 효과와 혼합하지 않는다.
- 코스튬 정의: 외형, 고정 무기, 성급별 무기 효과, 궁극기 생성 카드. 전투 상태: 마나, 궁극기 게이지, 현재 단계, 고정 실행 순서, 무기 턴당 발동 여부.
- 아트 목표: 32×32 하드 픽셀, 그림과 UGUI 텍스트 분리. 기존 생성 이미지는 시안이며 규격 미달 탄환 이미지는 완성 에셋으로 간주하지 않는다.
