# 카드 디자인 및 프로토타입 기획안

2026-11-01. 사용자 스케치를 바탕으로 한 제안안. 게임 구현 및 밸런스 확정 전 문서.

## 명칭과 방향

- 기존 참고작의 캔디 계열 → 폭렬 계열. 피해량 전달·증폭과 마지막 폭발이 중심.
- 기존 참고작의 너구리 계열 → 사냥꾼 계열. 이번 제안에서는 파워를 적의 표식으로 재해석해 준비·추적·마무리를 표현한다.
- 공통 계열을 추가한다. 기본 공격, 배치 순서 학습, 범용 강화, 합체 보조를 담당한다. 폭렬·사냥꾼 어느 쪽에도 속하지 않는 독립 계열이다.
- 나머지 계열은 이번 프로토타입 범위에서 제외한다.

## 카드 표시 규칙

| 위치 | 표시 |
| --- | --- |
| 좌측 상단 | 현재 대상과 앞선 카드 효과를 반영한 예상 1타 피해 × 타수. 서포트는 숫자 대신 서포트 아이콘 |
| 우측 상단 | 합체 등급 별 1~3개. 희귀도와 별개 |
| 상단 본문 | 일러스트. 그림 아래쪽에 카드명 |
| 중앙 가로 띠 | 계열 1 / 계열 2 / 종류. 단일 계열이면 계열 / 종류의 2칸으로 재분할 |
| 하단 본문 | 효과 설명 |
| 좌측 하단 | 턴 제한 카드만 모래시계 + 남은 턴 표시 |

계열은 공통(회백색, 마력 문양)·폭렬(주황, 불꽃)·사냥꾼(청록, 조준점). 종류는 공격·서포트 두 가지로 시작한다. 계열과 종류는 별도 데이터이며, 공격/서포트를 두 번째 계열로 취급하지 않는다. 복합 카드는 양쪽 계열의 효과를 모두 받되, 동일 효과를 중복 적용하지 않는다. 공통 카드는 `공통 / 공격` 또는 `공통 / 서포트` 2칸으로 표시한다. 공통을 모든 카드의 추가 계열로 붙이지 않는다.

## 공통 전투 규칙 제안

1. 시퀀스는 왼쪽부터 실행하며 빈 슬롯은 건너뛴다. 프로토타입은 현재 대상 한 명을 기준으로 한다.
2. 표의 수치는 별 1 기준이다. 최종 1타 피해 = 내림((기본 피해 + 고정 증가 + 전달 피해 + 조건부 증가) × 배율). 총 피해는 1타 피해 × 타수다. 방어 효과는 초기 검증에서 제외한다.
3. 같은 공격 카드의 타격들은 하나의 카드 사용으로 센다. 표식 소모와 '다음 공격' 버프 소모는 모든 타격이 끝난 뒤 처리한다.
4. 표식은 대상별로 최대 5개. 해당 턴 종료 시 사라지며 다른 대상으로 이전하지 않는다. 지정된 마무리 카드만 표식을 소비한다.
5. 모든 피해 버프·전달·계열 사용 횟수는 그 턴에만 유효하다. 사용 횟수는 공격·서포트 모두 포함하되, 현재 카드 자신은 제외한다. 카드 재배치 시 예상 피해를 다시 계산한다.
6. '다음 폭렬 공격'은 서포트나 다른 계열을 건너뛰어 다음 조건 충족 카드에 적용한다. 해당 카드가 없으면 턴 종료 시 소멸한다. 배율 버프가 여러 개면 서로 곱한다.
7. 제한 턴은 배치 후 실제로 그 카드가 발동한 턴에만 1 감소한다. 0이면 시퀀스에서 제거되어 전투 중 다시 사용할 수 없다. 보관 중에는 감소하지 않는다. 다른 카드는 전투 중 반복 사용한다.
8. 동일 카드·동일 별 2장을 합쳐 다음 별로 승급한다. 최대 별 3. 별 2/3의 기본 피해·고정 수치 증가는 별 1의 2배/4배로 시작한다. 타수·배율·표식 개수·제한 턴은 유지한다. 제한 카드 합체는 두 재료 중 낮은 남은 턴을 계승하며, 미배치 재료는 기본 제한 턴으로 계산한다.
9. 공격 예상치는 해당 슬롯에 도달했을 때의 표식과 버프를 순서대로 모의 계산한다. 대상이 없으면 기본 피해를 보여준다. 실제 적용·미리보기는 같은 계산 규칙을 사용한다.

## 공통 계열의 세부 규칙

- 역할: 전용 계열 카드가 부족한 초반을 채우고, 첫 카드·마지막 카드·다단 공격·합체를 학습하게 한다. 표식 생성, 폭렬 횟수 보너스, 폭렬 피해 전달 효과는 직접 제공하지 않는다.
- 공통은 독립 계열이다. 공통 카드 사용은 폭렬 사용 횟수에 포함되지 않으며 폭렬·사냥꾼 전용 버프를 받지 않는다. 계열 제한 없는 버프는 어떤 계열에도 적용한다.
- 선제 사격과 최후의 일격은 빈 슬롯을 제외한 실제 발동 순서로 판정한다. 서포트도 순서에 포함한다. 카드가 한 장뿐이면 첫 번째이자 마지막이다. 발동 도중 제거되는 카드가 생겨도 이번 턴의 마지막 슬롯 판정은 턴 시작 시 확정한 실행 목록을 기준으로 한다.
- 마력 집중은 서포트를 건너뛰고 다음 공격에서 소비된다. 무기 연마와 중첩 가능하다. 다단 공격의 모든 타격에 적용하되 카드 한 장을 사용한 것으로 처리한다.
- 잔상탄은 직전 공격의 기본 피해·타수만 가져온다. 버프, 전달 피해, 표식 추가 피해, 카드 효과, 남은 턴을 복사하지 않는다. 복사 후 현재 잔상탄에 적용되는 범용 버프를 계산한다. 앞에 공격이 없으면 0 × 1, 공격 발동 없이 건너뛰며 다음 공격용 버프를 소비하지 않는다.
- 잔상탄은 승급 수치의 예외로, 자신의 별 1/2/3에 따라 복사한 기본 피해의 100%/125%/150%를 사용하고 소수점을 버린다. 타수는 유지한다. 잔상탄이 잔상탄을 참조하면 최초 원본 공격의 기본 피해·타수를 참조해 자신의 배율만 적용한다. 복사 배율이 연쇄 증폭되지 않는다.
- 합성 촉매는 준비 단계에 사용하는 서포트다. 별 1인 일반 소유 카드만 대상으로 하며 자신과 다른 촉매는 대상으로 지정할 수 없다. 대상 카드의 제한 턴은 회복하지 않는다. 촉매 자체는 별 1 고정, 합체 불가다. 대상 선택 전에는 소모하지 않는다.
- 일회용 촉매는 모래시계 대신 설명에 '사용 시 소모'를 표시한다. 모래시계는 남은 사용 턴에만 사용한다.
- 프로토타입 지급안: 마력탄 2장, 선제 사격 1장, 마력 집중 1장으로 시작한다. 마력탄 두 장으로 첫 합체를 체험한다. 최후의 일격·무기 연마·잔상탄은 보상 후보, 합성 촉매는 첫 합체 튜토리얼 후 확정 보상으로 둔다. 경제·상점 시스템 없이도 검증할 수 있다.

## 검증용 배치 예시

별 1, 표식·버프 없는 대상에서 시작한다.

- 폭렬: 화약 장전 → 도화선 → 폭렬. 도화선 23 피해, 폭렬은 60 + 5 + 23 + (10 × 2) = 108 피해. 총 131.
- 사냥꾼: 조준 → 사냥 화살 → 사냥 본능 → 마무리 사격. 사냥 화살 12 피해 및 표식 총 3개, 마무리 사격 20 + 5 + (8 × 3) = 49 피해. 총 61.
- 복합: 조준 → 화약 덫 → 폭렬 추적탄. 표식 4개, 추적탄 (20 + 10 + 5 × 4) × 2 = 100 피해. 공격 후 표식 0개, 추적탄 남은 턴 1.
- 공통 기본: 선제 사격 → 마력 집중 → 마력탄. 선제 사격 24, 마력탄 (8 + 8) × 2 = 32. 총 56.
- 공통 다단: 무기 연마 → 연사 → 잔상탄. 연사 (6 + 3) × 3 = 27, 잔상탄은 연사의 기본 6 × 3을 복사한 후 연마를 받아 27. 총 54.
- 순서 판정: 마력 집중 → 선제 사격은 선제 조건 불충족으로 12 + 8 = 20. 최후의 일격 → 마력 집중은 마지막 카드가 서포트이므로 최후 조건 불충족으로 12.

위 예시는 기능 검증용이며 같은 길이·같은 비용의 균형을 뜻하지 않는다. 계열별 승률·피해 편차는 플레이 테스트 후 조정한다.

## 구현 시 최소 데이터

카드 ID, 카드명, 계열 목록(1~2개), 종류, 그림, 기본 피해, 타수, 효과 목록, 합체 등급, 기본 제한 턴, 사용 단계(준비/전투), 일회용 여부, 합체 가능 여부를 정의 데이터로 둔다. 남은 턴은 소유 카드별 상태로 보관한다. 예상 피해는 런타임 계산값이다. 기존 CardUIData의 category 문자열 하나로 계열과 종류를 겸하지 않는다.

이 문서는 기획과 컨셉 이미지 전달 범위이며 실제 카드 데이터·UGUI·전투 로직 변경은 포함하지 않는다.
